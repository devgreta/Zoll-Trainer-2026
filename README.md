# Zoll Einstellungstest Trainer 2026

Ein interaktiver, browserbasierter Quiz-Trainer zur Vorbereitung auf den Zoll Einstellungstest 2026.

## Funktionen

- Übungsfragen im Quizformat
- Startbildschirm und interaktiver Quizmodus
- Antwortauswertung
- Fortschrittsanzeige
- Wiederholungs- und Review-Funktionen
- Für Desktop und mobile Geräte nutzbar

## Nutzung

Die Anwendung läuft direkt im Browser.  
Nach dem Öffnen der Seite kann der Quizmodus gestartet und die Fragen können Schritt für Schritt bearbeitet werden.

## Zweck

Dieses Projekt dient der strukturierten Vorbereitung auf den Zoll Einstellungstest und bietet prüfungsnahe Übungsfragen für Bewerberinnen und Bewerber.
